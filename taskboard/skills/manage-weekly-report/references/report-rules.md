# Weekly report rules

## Canonical structure

Use Simplified Chinese in this order:

1. `# 本周工作`
2. `## 团队进度汇报`
3. `### 一、商业化`
4. `### 二、Agent`
5. `## 本周思考`
6. `### 工作思考`
7. `### 外部技术学习`
8. `## 下周工作`

Retain `一、商业化` and `二、Agent` by default. Group progress by business line, version, or project.

## Content rules

- Use `●` for main progress, `○` for milestones, details, or owners, and `■` for deeper subprogress.
- Preserve supplied dates, status, and `负责人：姓名` exactly when supported by evidence.
- Keep wording concise, neutral, factual, and management-oriented.
- Describe background, progress, risk, and reflection without inflated praise or blame.
- Do not invent progress, dates, projects, owners, risks, or next-week work.
- Keep `工作思考` about the current week's work. Put verified AI or Agent developments under `外部技术学习`.
- If external-learning material is missing, verify current information from primary sources, draft it separately, and ask the user to confirm it.
- Keep `下周工作` to about three short, high-priority actions derived only from confirmed progress or plans.

## Commercialization registry

Treat `ADX`, `高拍仪`, and `企业版` as the persistent commercialization registry. Omit a line that has no reportable progress for the current week; omission does not remove it from the registry. Add temporary or new projects only when supplied.

Normalize a responsible person's name only when identity is clear. Known spellings include `魏波`, `吴钰杰`, `黄镇`, `雷诗城`, `戴伊晗`, and `张佳妮`. Ask one focused question when a similar name could refer to a different person. Do not treat historical assignments as permanent roles.

## Collection and confirmation

- Ask one focused question, then wait.
- Reuse already supplied facts instead of asking again.
- Stop immediately when the user says to pause or stop.
- Present one complete report for confirmation after the facts are sufficient.
- Archive only the complete report explicitly confirmed as correct or final.
