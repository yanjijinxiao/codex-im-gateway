MESSAGE CHANNEL

添加消息渠道

个人微信添加教程约 1 分钟
  1. 1

    点击下方“扫码登录”，页面会生成专用二维码。

  2. 2

    使用要接入的个人微信扫码，并在手机上确认登录。

  3. 3

    登录成功后，给机器人发送一条消息，再回管理页允许该联系人访问。

无需前往其他后台配置，直接点击下方“扫码登录”。
企业微信添加教程需要管理员权限
  1. 1

    在企业微信工作台进入“智能机器人”，创建一个 API 模式机器人。

  2. 2

    在机器人 API 设置中选择 WebSocket 长连接，无需填写公网回调地址。

  3. 3

    复制机器人页面提供的 Bot ID 和 Secret，填入下方对应字段。

  4. 4

    添加完成后，在企业微信中向机器人发送一条消息，系统会自动登记接收会话。

创建智能机器人需在企业微信客户端的“工作台”中完成。
打开企业微信管理后台查看官方长连接文档
飞书添加教程企业自建应用
  1. 1

    进入飞书开放平台“开发者后台”，创建 企业自建应用，并添加机器人能力。

  2. 2

    在“凭证与基础信息”复制 App ID 和 App Secret，填入下方字段。

  3. 3

    开通机器人收发消息权限：单聊消息、群聊中 @ 机器人消息、以应用身份发消息。

  4. 4

    在“事件与回调”选择 长连接，添加“接收消息”事件 im.message.receive_v1，并订阅卡片回调 card.action.trigger。

  5. 5

    创建版本并发布应用，再向机器人发送一条消息以登记接收会话。

打开飞书开发者后台查看官方长连接文档
钉钉添加教程企业内部应用
  1. 1

    进入钉钉开放平台，创建 企业内部应用，在“凭证与基础信息”复制 Client ID 和 Client Secret。

  2. 2

    在“应用能力”中添加机器人，消息接收模式选择 Stream 模式，无需公网回调地址。

  3. 3

    可选：在卡片平台创建含 Markdown 字段的 AI Card 模板，并填写模板 ID 与对应内容字段名。

  4. 4

    完成机器人配置并发布应用，再把机器人加入目标群或直接发起单聊。

  5. 5

    向机器人发送一条消息以登记会话；之后即可使用 /sessions、/session R1 和 /new。

打开钉钉开发者后台查看官方 Stream 文档
