PROJECT DEVELOPMENT

项目 Web IDE

本机项目本机运行，远程项目远程运行。Gateway 统一授权，无需另设 IDE 密码。每个实例拥有独立数据目录；仅供项目所有者使用，不是多用户沙箱。

选择已配置固定 HTTPS 的远程主机后，项目默认发布该共享入口；启用下方「本机项目直连」时，仅本机项目改用自己的入口，远程项目不变。每个项目只发布一个链接，手机和电脑共用；127.0.0.1 只用于本机维护。

共享入口中断时不回退到其他地址，后台自动重连。手机需能通过公司内网/VPN 访问对应端口并信任证书；本机休眠或离线时入口也暂不可用。请勿公开 Gateway 管理端口。

本机项目 · 内网 / VPN 直连

保存时使用原有 CA 自动准备该 IP 的证书，只开放 IDE 数据面，审批仍由 Gateway 负责；不开放管理端口或裸 code-server。本机维护入口和远程入口不变。

自动模式每 3 秒检测指定网卡，地址变化后自动更新监听、证书和新链接；网卡离线或有多个 IPv4 时暂停入口，恢复后自动重试。固定模式需手动更换 IP。旧 IP 链接无法重定向，IP 变化后浏览器需重新批准；其他入口授权保留。手机连通性需单独确认。

本机访问可使用回环 HTTP；内网/VPN 可启用下方内置 HTTPS，无需另装反向代理。不要公开 Gateway 管理端口。
共享入口 · 内网 / VPN HTTPS

只监听所选接口，不监听全部网卡。VPN 断开或 IP 改变时需要重新配置，证书不能解决 VPN 的入站访问限制。

生成证书只填入本表单，点击「保存并应用」后才启用入口。每台访问设备需自行导入并信任 CA，不能仅忽略浏览器警告；不提供额外 IDE 密码。CA 私钥不会下载、上传或自动加入系统信任库。

未配置内置 HTTPS。

下载本地 CA 证书（供访问设备信任）
允许运行的主机

通过已登记的 SSH 配置连接。可授权在用户专用目录自动安装 code-server（支持 Linux x64、macOS Intel / Apple Silicon）；主机需已有 Node，不使用 sudo，也不修改系统服务。

新机器的项目登记后，刷新本页并勾选对应主机，保存即可热接入，无需重启 Gateway。选择共享入口时，新项目主机的远程入口字段可留空：复用已有转发器，不新增 Web 端口。发现 session 不等于自动授予安装或浏览器访问权限。

默认编辑器 Profile

新实例使用此基线；已有实例只补缺失的默认项，不覆盖用户设置或项目 .vscode。缺省外观为 Dark 2026、Seti 文件图标、Default 界面图标、Menlo / Monaco / Courier New 等宽字体、12px 字号、18px 行高、普通字重、关闭连字、标签页换行；字体由浏览器设备提供。Chat 所在的右侧面板默认收起，可手动打开；已保存的布局仍由 IDE 记忆。修改 Profile 后使用独立的新实例目录。

保存即声明所选扩展：打开对应实例时核验并从 Open VSX 安装缺失项，已安装的不重复下载；也可先在会话页「准备扩展」。失败不阻止编辑器打开，下方显示实际安装结果。语言工具链需在项目所在主机配置；安装成功不等于语言功能已验收。

主机访问入口

跨设备 · 复用个人准入

在聊天授权中「允许此用户」后，该个人即可通过 /ide 为本人浏览器配对，无需另行登记 IDE 管理员。权限包含本渠道账号关联项目的代码编辑、终端与所选目录信任，不授予 Gateway 管理权限。允许整个群、session 角色和绑定关系不授予个人 IDE 配对资格；渠道必须提供明确会话类型和真实发送人。撤销个人准入同时使由它签发的 IDE 登录失效；重新允许不会恢复旧登录。个人准入与浏览器授权均跨重启保留。

旧版独立登记兼容

原有独立身份保留，不会自动加入 IM 准入名单。新用户应使用上面的个人准入方式；可发送 /ide identity 核对本人资格。

添加仅授予兼容配对资格，不直接批准浏览器或授予 IM 权限；移除使该资格新签发且记录了来源的浏览器登录失效。旧版未记录个人来源的授权仍按原到期时间保留，必要时单独撤销。

浏览器访问授权

新授权有效期为 以服务端显示为准，Gateway 重启后仍保留，不自动延期。旧版已签发的授权继续按原到期时间生效，不清空、不静默续期；未记录个人来源的旧授权不能追溯到 IM 用户，需另行撤销。新增主机或重复保存不会撤销已有授权；停用主机、改变可执行文件或 Profile 时只撤销受影响主机，改变入口安全边界时只撤销对应入口。本机会话页的「Web IDE · 授权并信任」会一并启用当前目录的任务、调试和扩展。其他设备从原浏览器授权页复制一种短命令，由已获个人准入的本人在对应机器人私聊或群聊发送一次即可处理；不要求聊天绑定 session。只配对你本人发起的申请。
