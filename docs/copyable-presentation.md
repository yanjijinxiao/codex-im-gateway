# 统一复制呈现

凡是需要人复制、回填或选择的值，独立呈现；不要让人从一段说明中截取 ID、命令或选项。复制不是执行或提交。

## 网页

管理后台、独立 IDE 页面和任务面板共用 `src/web/copyable.js`、`copyable.css`。管理页直接加载，IDE SSR 使用同一脚本和样式，任务面板在 `web/src/main.tsx` 引入。动态插入的表单字段、代码/ID、Markdown 选项和菜单选项自动增强，无需每个页面自行实现剪贴板逻辑。下拉框支持复制当前值和逐项展开复制；每个值有自己的独立框。

语义化 `input`、`textarea`、`select`、`code`、`pre` 和选项角色即可接入；其他需要回填的展示值标记 `data-copy-output`（可指定完整值），或使用 `window.gatewayCopy.field(label, value)` / SSR `copyField`。敏感或不应复制的区域显式标记 `data-copy-ignore`。隐藏/密码/文件字段不自动加入，CSRF 和授权票据不进入复制控件。

只读框、复制按钮和反馈分离；不重建或替换输入节点，避免轮询抢焦点。复制事件在捕获阶段阻止行点击、链接或表单的默认操作。内容以文本转义，不生成内联事件处理器。点击复制后保留手动复制框；程序化剪贴板受限时，不要求用户另找原值。浏览器 API 完成只显示「已请求复制」，不读取用户剪贴板，也不把 API 返回成功当作实际粘贴验收。

## IM

`src/channels/copyable.ts` 提供 `copyBlock` 和幂等的 `copyableChoices`。每项真实响应放进一个独立代码块，解释和选项标签放在块外；围栏长度按内容计算。不要把多个选项、说明、序号或秘密混入待复制值。

`createChoiceCard` 覆盖问题、审批、模式、项目、会话、模型等公共选择卡。内部回调含隐藏 ID 时，用 `copyValue` 指定公开的当前用户目录编号，例如 `/session R1`，不把内部会话 ID 显示出来。`copyableTaskCard` 同时用于原生任务卡和文本降级，覆盖任务操作及表单枚举选项。原生可操作按钮继续保留，但代码块本身不执行回调。复制格式不修改接收端命令、审批资格、原生 request ID 或提交去重规则。IM 长内容统一使用保留 Markdown 围栏的 `resultPages`，不按字符直接截断复制框。

Bridge 提示策略要求模型提出任何问题、选项或需要回填的命令/ID 时使用同样的独立块。自由文本答案仍由用户明确发送，密码类问题继续在 Codex App 内回答，不转到 IM。

## 验收路径

网页显示一个真实选项 → 点击它的复制按钮 → 只读框显示精确值、反馈结果 → 粘贴核对；原表单和选中项应不变。对只读框手动复制是内嵌浏览器受限时的可用路径。任务面板使用自身的 React 页面验证同一条操作链，不以静态 HTML 样例代替实际接入。

IDE 另核验：原浏览器完成授权 → 自动进入 IDE → 再打开相同链接直接进入；新浏览器、撤销或过期的授权仍需批准，不能把便捷跳转实现成鉴权旁路。
